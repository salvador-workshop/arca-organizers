# arca-organizers

Salvador Workshop's 3D [Code-CAD](https://github.com/Irev-Dev/curated-code-cad) tools for creating models of tools and utilities for organizing spaces.

## Usage

1. open the `sw-jscad-viewer` locally, or online (<https://sw-jscad-viewer.netlify.app/>)
1. on your file explorer, drag the `packages/pegboard` folder into the browser window
